# Changelog: 2025-12-02

## Summary

Major cleanup session: Fixed 16 critical bugs, implemented undo system for MIDI editing, and added essential keyboard shortcuts.

---

## Bug Fixes (16 Critical Issues)

### MIDI Engine Fixes

1. **SnapMode::None Bug** (`project.rs`)
   - "No snap" mode was snapping to beats instead of allowing free placement
   - Fixed: Returns `0.0` for no snapping

2. **UI/Engine Time Desync** (`commands.rs`)
   - Seek command updated UI but not engine, causing playhead desync
   - Fixed: SeekTime now sends SetPosition to engine

3. **SetTempo Spam** (`app.rs`)
   - Tempo command sent every frame (~60fps) regardless of changes
   - Fixed: Only send on BPM change with `last_bpm_sent` tracking

4. **Engine Time Authority** (`state.rs`)
   - Two sources of truth for playhead time caused jitter
   - Fixed: Engine is now authoritative source when active

5. **NoteOn Velocity 0** (`midi_engine.rs`)
   - NoteOn with velocity 0 not treated as NoteOff per MIDI spec
   - Fixed: Converts to NoteOff

6. **All Notes Off Optimization** (`midi_engine.rs`)
   - Sent 2048 individual NoteOff messages (16 channels x 128 keys)
   - Fixed: Use CC 123 - only 16 messages (99.2% reduction)

7. **Duplicate MIDI Event Scheduling** (`app.rs`)
   - UI scheduled events every frame with no deduplication
   - Fixed: Watermark system tracks last scheduled beat

8. **Recording Timestamps** (`midi_recording.rs`)
   - Hardcoded 120 BPM never updated with project tempo
   - Fixed: Added SetTempo command to recording coordinator

9. **Recorded MIDI Clip Saving** (`app.rs`)
   - Clips used placeholder path "recorded.mid"
   - Fixed: Generate unique filenames in project's midi/ directory

10. **MIDI Tempo Mapping** (`midi.rs`)
    - Multiple tempo changes computed incorrectly
    - Fixed: Accumulate time across all tempo segments

11. **Unbounded Channels** (`midi_engine.rs`, `state.rs`)
    - Risk of unlimited memory growth
    - Fixed: Bounded channels (1000/500/2000 limits)

12. **Lock Contention** (`midi_engine.rs`)
    - Locks held during MIDI I/O caused latency
    - Fixed: Staged processing with locks released between stages

13. **Metronome Port Selection** (`midi_engine.rs`)
    - Selected first port nondeterministically from HashMap
    - Fixed: Dedicated metronome_port field with SetMetronomePort command

14. **Removed Unused Code** (`midi_engine.rs`)
    - RecordingEvent variant never constructed or used
    - Removed

### Performance Improvements
- 99.2% reduction in "All Notes Off" messages
- ~60x reduction in SetTempo messages
- Eliminated duplicate MIDI scheduling
- Eliminated timing jitter
- Reduced lock contention

## Undo System Implementation

Implemented full undo/redo for core MIDI editing operations:

### DeleteNotes Undo
- Added `deleted_notes` field to store deleted notes
- Collects notes before deletion
- Undo restores via `add_note()`

### ResizeNote Undo
- Added `old_start_time` and `old_duration` fields
- Captures original values during resize drag
- Undo restores original dimensions

### UpdateNoteVelocity Undo
- Added `old_velocity` field
- Captures current velocity when dragging
- Undo restores original velocity

## Keyboard Shortcuts Implementation

### Selection
- **Ctrl+A** - Select all notes in clip
- **Shift+Drag** - Selection box
- **Escape** - Clear selection

### Copy/Paste/Duplicate
- **Ctrl+C** - Copy selected notes
- **Ctrl+V** - Paste at playhead position
- **Ctrl+D** - Duplicate notes (places after originals)

### Editing
- **Delete/Backspace** - Delete selected notes
- **Q** - Quantize selected notes

### Implementation Details
- Internal clipboard stores full Note objects
- Paste calculates offset from earliest note
- Duplicate offsets from end of latest note
