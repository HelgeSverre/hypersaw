# Changelog: 2025-12-03

## Summary

Piano roll UX improvements: Enhanced selection, multi-note operations, keyboard navigation, and view switching.

---

## Piano Roll Improvements

### Lasso Selection - Visual Intersection

**Before:** Selection box required full containment of note's pitch row
**After:** Any visual overlap with selection box selects the note

- Changed from coordinate-based filtering to `rect.intersects()` check
- Partial overlap now correctly selects notes
- File: `src/ui/piano_roll.rs` (lines 1456-1491)

### Multi-Note Resize with Collective Clamping

**Before:** Only the dragged note resized
**After:** All selected notes resize together

- Added `ResizeNotes` command for batch resize with single undo step
- Collective clamping: If any note reaches minimum duration (0.1s), ALL notes stop resizing
- Both left and right edge resize supported
- File: `src/ui/piano_roll.rs`, `src/core/commands.rs`

### Ctrl+Drag to Duplicate

Hold Ctrl/Cmd while dragging selected notes to create duplicates:

1. Ctrl+drag starts → Notes appear to move (visual preview)
2. On release → Duplicates created at final position
3. Originals remain in place

- Decision made at drag start (releasing Ctrl mid-drag still duplicates)
- Works with single or multiple notes
- Respects grid snap
- File: `src/ui/piano_roll.rs` (lines 635-777)

### Arrow Key Nudging

| Keys | Action |
|------|--------|
| `←` / `→` | Move selected notes by one grid snap unit |
| `Shift + ←` / `→` | Move selected notes by one beat |
| `↑` / `↓` | Transpose selected notes by ±1 semitone |
| `Shift + ↑` / `↓` | Transpose by ±12 semitones (one octave) |

- Collective clamping prevents notes from going before time 0
- Pitch clamped to MIDI range 0-127
- Falls back to beat if grid snap is None
- File: `src/ui/piano_roll.rs` (lines 501-575)

## Timeline Improvements

### Track Header Redesign

**Before:** Entire track header was a drag zone, stealing focus from clicks
**After:** 16px drag handle on left side only

- Added grip dots visual (⋮⋮) in drag zone
- Content zone now properly receives click events
- File: `src/ui/timeline.rs` (lines 686-750)

### Track Renaming

- Double-click track name to edit inline
- Enter to confirm, Escape to cancel
- Added `RenameTrack` command
- File: `src/ui/timeline.rs`, `src/core/commands.rs`

---

## View Switching

Added Bitwig-style keyboard shortcuts for view navigation:

| Keys | Action |
|------|--------|
| `Cmd+1` | Switch to Arrangement view |
| `Cmd+2` | Open Piano Roll (if clip selected) |
| `Escape` | Return to Arrangement from any editor |

- Added View menu with these options
- File: `src/ui/app.rs` (lines 873-920)

> Current behavior (2026-08-09): Escape is editor-local for cancel/deselect so it does not
> preempt egui child interactions. Cmd/Ctrl+1 is the stable shortcut for Arrangement.
